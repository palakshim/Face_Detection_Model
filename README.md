# 👁️ Real-Time Face Detection using OpenCV

This project is a Python-based real-time face detection system using **OpenCV** and a pre-trained **Haar Cascade Classifier**. It captures video from the webcam, detects faces in each frame, and highlights them with rectangles.

---

## 🔍 Features

- Real-time face detection from webcam feed
- Uses Haar cascade classifier for accuracy and speed
- Highlights faces with green rectangles
- Simple to run and modify

---

## 🧠 Concepts Used

- **Computer Vision**
- **Haar Cascade Classifier**
- **Image Processing with OpenCV**
- **Video Capture and Frame-by-Frame Analysis**
